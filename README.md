# Ashvini Kumar — 3D portfolio

Live portfolio: [bettercallashvini.com](https://bettercallashvini.com/)

Selected product models, interactive scenes, and motion studies by Ashvini Kumar. The site is built with React and Vite, with Spline scenes on supported desktop devices and lightweight still renders on smaller screens.

## Local development

```bash
npm install
npm run dev
```

`npm run build` produces the site in `dist/`, including route-specific HTML, a sitemap, and a 404 page for Cloudflare Pages.
